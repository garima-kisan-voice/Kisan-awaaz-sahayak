# Kisan Awaaz Sahayak (किसान आवाज़ सहायक)

**"बोलो और सुनो"** पर आधारित एक आवाज़-प्रधान कृषि सहायक, जिसे इस तरह बनाया गया है कि कम पढ़े-लिखे या दूसरों पर निर्भर किसानों को बार-बार किसी से पढ़वाना न पड़े।

## मुख्य विशेषताएँ
* **मंडी भाव और बाज़ार मांग (मुख्य फ्लो):** फसल चुनने या बोलकर पूछने पर भाव की रेंज, किन मंडियों में अधिक मांग है, और बेचने/तैयारी की सरल सलाह सुनाई व दिखाई देती है।
* **१-मिनट वॉइस ट्रायल:** ऐप का उपयोग शुरू करने का तरीका सीधे आवाज़ में समझाया जाता है।
* **खेती के अन्य सहायक मॉड्यूल:** घर बैठे बीज व उर्वरक, फसल कीट व बीमारी, सिंचाई व जल बचत, तथा भाड़े पर साधन व छुट्टा जानवर से जुड़ी जानकारी।
* **बिना किसी Secret Key के चलने योग्य:** मुख्य ऐप बिना किसी बाहरी API key के सीधे शुरू होता है।
